# Inter Variable

Unmodified Inter Variable from the upstream Inter v4.1 release tag.

- Source: https://github.com/rsms/inter/tree/v4.1
- Font: https://raw.githubusercontent.com/rsms/inter/v4.1/docs/font-files/InterVariable.woff2
- License: SIL Open Font License 1.1; the upstream `LICENSE.txt` is included here.

Served locally so the interface does not depend on an installed font or an external font service. The font is used for application UI; canvas document font selections are unchanged.
